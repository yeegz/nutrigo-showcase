# Screenshot provenance

Captured September 21 and refreshed September 27, 2026 from the running NutriGo Flutter app on an Android API 35 emulator. These are actual Flutter-rendered screens, not product mockups. They omit Android system bars. The screenshots/ios folder contains separate actual iPhone simulator captures made September 27. These show the native iOS navigation controls. All captures omit system status bars; none are presented as physical-device verification.

A dedicated local Firebase emulator account supplies synthetic meals, weights, friends and posts. USDA food search and MedlinePlus recipe retrieval were exercised against their live public APIs/pages. Example nutrition and targets in screenshots belong to synthetic QA data and are not recommendations. The breakfast image in a private sample post is an illustration.

Dark and light screenshots show the same development account. Application source, account configuration, backend credentials and private user feedback screenshots are excluded from this repository.

The source app is private. This repository contains only the presentation, screenshots and licensed brand font assets. Switzer and Clash Grotesk are from Indian Type Foundry/Fontshare; their redistribution terms are included under assets/fonts. Food emoji visible within screenshots come from Microsoft Fluent Emoji (MIT); the license is included under assets.

The screenshots/widgets folder is rendered by Android's actual RemoteViews framework in instrumentation tests. It uses synthetic 60 g protein / 120 g target and 750 ml water data. These images show the implemented native layouts, not a physical home or lock-screen host. They are not iOS WidgetKit screenshots.
